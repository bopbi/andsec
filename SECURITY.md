# Security Policy

AndSec is an educational repository that deliberately demonstrates vulnerability classes in synthetic apps. An intentional weakness documented as part of a lab is not, by itself, a security issue in this repository.

Please report unintended behavior such as:

- a lab interacting with third-party apps, real accounts, personal data, or undocumented external services;
- a demonstration exceeding its documented permissions, scope, or user-consent boundary;
- credentials, private keys, personal information, or other sensitive material accidentally included in the repository;
- unsafe instructions that could affect a personal device or non-lab data.

Do not include real credentials, personal data, exploit details affecting third parties, or other sensitive material in a public issue. Use GitHub's private vulnerability reporting for this repository if it is available; otherwise, contact the repository owner through their GitHub profile before public disclosure. Include the affected lab, Android API level, reproduction steps using only synthetic data, and the expected versus actual behavior.

For ordinary documentation corrections and non-sensitive lab defects, open a regular GitHub issue. Contributions must follow the safety rules in [CONTRIBUTING.md](CONTRIBUTING.md).

This repository does not provide a service-level guarantee or a formal bug bounty. Reports will be assessed and addressed as maintainers' time permits.
